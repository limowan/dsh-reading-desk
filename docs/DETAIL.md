# 读书台

把微信读书的阅读计划、月历、划线回顾、笔记和月度阅读展放进 DeepSeek Harness 的侧栏面板。

## 怎么用

1. 侧栏点「读书台」图标，面板里就是完整的读书台界面。
2. 「本月书单」里搜索书、用日期区间把书排进本月；「月度日历」看每天读什么。
3. 「每日划线回顾」按 FSRS 排到期卡片；「笔记」记录与 AI 讨论后的结果。
4. 第一次使用只有内置的公开书目；要显示自己的数据，在面板里点「连接微信读书」填入
   Agent Gateway 的 API Key 同步一次，数据只存在这台机器的浏览器里。

## 实现

- 宿主侧：`index.js` 用 `ctx.webServer` 挂两个路由
  - `prefix /plugin/reading-desk`：把 `assets/` 里的界面托管出来
  - `exact /api/weread`：把面板发来的只读请求原样转发给微信读书网关（不落盘、不记日志）
- 浏览器侧：`client.js` 注册一个侧栏图标（`sidebar.panellist`）和一个主面板（`main`），
  面板里用 iframe 载入上面那个界面。

## 已知限制

- **只有界面已接入**：内置数据是公开样张；自己的数据要手动同步一次，且存在浏览器里。
- **API Key 由页面持有**：沿用原界面的做法，Key 存在浏览器 localStorage，随请求发给本插件的转发路由。
  后续可改为宿主侧保存。
- **AI 分析是占位**：阅读性格里的解读、笔记里的讨论回复目前是模板文案，还没接 `ctx.llm`。
- **未验证**：面板高度、明暗主题跟随、移动端表现需要在真实 dsh 里再看一遍。
